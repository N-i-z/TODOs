# TODOs

Full-stack TODO app using React and Node.js, built as a monorepo with clean architecture and RESTful APIs

## Scripts

- **dev:client**: Start the Next.js client dev server.
- **dev:server**: Start the NestJS server in watch mode.
- **build:client**: Build the Next.js client.
- **build:server**: Build the NestJS server.
- **build:ui**: Build the shared UI package.

### Usage

```bash
pnpm run dev:client
pnpm run dev:server
pnpm run build:client
pnpm run build:server
```
